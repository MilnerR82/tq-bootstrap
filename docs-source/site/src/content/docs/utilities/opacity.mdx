The `opacity` property sets the opacity level for an element. The opacity level describes the transparency level, where `1` is not transparent at all, `.5` is 50% visible, and `0` is completely transparent.

Set the `opacity` of an element using `.opacity-{value}` utilities.

<Callout type="warning">
**Transparency demonstration:** empty decorative colour blocks show the actual utility opacity. Their readable labels stay fully opaque. The live example, copyable markup and editor export use the same classes and values. Do not reduce essential reading text below its required contrast.
</Callout>

<p>Example values, from left to right: 100%, 75%, 50%, 25% and 0% opacity. The last sample is fully transparent.</p>

