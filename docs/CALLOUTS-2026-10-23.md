# Documentation callout update — 23 October 2026

The initial requested changes applied to the shared documentation callouts: info used a white surface with a TQ Red side border and charcoal text, including in dark mode. Warning and danger retained their semantic colours with static 135-degree diagonal stripes, alternating 8px bands. Forced-colour mode removes the decorative stripes and uses system colours. Native callout spacing, borders, dimensions and typography are retained. The plain base example's unreadable dark-mode text was also corrected.

Sources: `docs-source/site/src/scss/_tq-docs.scss` and `docs-source/site/src/content/docs/customize/components.mdx`. Framework alerts and upstream sources are unchanged. The documentation build regenerated and published 176 pages, refreshing the existing compact downloads. The complete audited release ZIP was not rebuilt.

Focused verification: in-app Chromium browser, desktop, Components, Sass and JavaScript documentation in light and dark modes. All 66 sampled text elements passed 4.5:1 against both stripe bands; minimum measured contrast was 7.24:1. Components-page callout widths, heights, padding, margins, border widths, corner radii and fonts matched before/after. The plain base example now measures 10.98:1 in dark mode. See `qa/results/callout-review-20261023/review.json` and `callouts.png`.

This is a focused visual/contrast check, not a renewed complete-page accessibility or release audit. Mobile, other browser engines, forced-colour rendering and assistive technology were not retested for this update. Original release evidence retains its original scope and input bindings.

## Subsequent lighter-fill refinement

At the user's request, info now uses a faint Koala Grey L2 tint (#f8f7f6, approximately 50% #f1efed mixed with white). Warning and danger fills mix 30% of their semantic subtle background with 70% of the current page background; stripe opacity is reduced to 4% and 3% respectively. Side-border colours and dimensions are unchanged. The 176-page documentation build and publication succeeded again.

The Components page was checked in the in-app Chromium browser in light and dark modes. All eight callout/mode combinations passed 4.5:1 for body text on both stripe bands; the lowest measured ratio was 6.20:1. Before/after borders, dimensions, spacing and fonts matched. This narrower follow-up does not replace the earlier measurements. Evidence: `qa/results/callout-lighter-20261023/review.json` and `callouts.png`.

## Current treatment: simplified warning and danger

Following the user's request to rethink the two patterned callouts, warning and danger now have plain tinted backgrounds and stronger side borders. Stripes are removed. Their fills mix 20% semantic subtle background with 80% page background. Warning uses Sunkissed #ff4904 at the side; danger uses Flame Tree Red D1 #8a0008 in light mode and Flame Tree Red L2 #fc545c in dark mode. Info retains its faint Koala Grey L2 tint and TQ Red side border. Native dimensions, spacing, fonts and border widths are unchanged.

The 176-page rebuild and local publication succeeded. Focused Chromium checks covered Components, Sass and JavaScript documentation in both modes: 66 text elements, no measured contrast failures, minimum 5.93:1. Evidence is saved separately at `qa/results/callout-simplified-20261023/review.json` and `callouts.png`. Earlier sections and reports describe superseded designs. No new complete release or full conformance audit was performed.
