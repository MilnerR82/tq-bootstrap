The following documented colour and accessibility adaptations are separately maintained in TQ source, without editing upstream.

The normal focus/outline context tokens reset on native reading panels and explicit background hosts, so nested panels use their own inherited paint context. Bright info/warning/light outline examples use the documented dark Indigo host. Their appearance on arbitrary future surfaces is not claimed to meet minimum contrast. Explicit low-alpha utility demonstrations retain the original alpha API and must be presented as identified diagnostic samples rather than ordinary focusable reading controls.

In normal modes the close-button pre-filter use of black/white is an implementation input to Bootstrap's unchanged invert/grayscale/brightness filter. Forced modes neutralise that filter and mask only the glyph with system paint, preserving the outer focus outline. Runtime pixel checks must verify the rendered result, rather than treating the pre-filter computed colour as the visible focus indicator.

`qa/compiled-parity.mjs` preserves both independent16-file native-source and16-file official-release comparisons and the original36 boundary probes. The current147 probes additionally cover utilities distribution paint and exact system/glyph/state adaptations, including rejection of the measured weak Highlight/HighlightText pair for selected labels and exact forced-carousel backing/inset focus. Twenty normal-control probes strictly limit the form border alias to its final colour slot after the unchanged native width/style, reject unknown variables/geometry, and verify the new normal state rules and actual compiled author overrides. Three further probes require the exact forced-progress fill/label utility precedence and reject an unknown context. Six indicator probes require its exact backing, paint precedence, native opacity, focus width/inset and selector context. `src/scss/_accessible-utility-colours.scss` gives the standalone utilities distribution the same supported focus/reading paint as the full framework, without adding component rules. Reboot retains the shared mode-aware root paint and opaque default; grid has no native focus helpers. `qa/remediation/focus-distributions.mjs` independently compares full/utility role and generic helpers with real Tab on controlled tabindex=0 anchors, expected colours, actual focus pixels, at least3:1 and native geometry in both modes and supported forced-colour schemes. An authored-colour capability probe must demonstrate automatic substitution to Canvas/CanvasText before forced assertions count; a matching media query alone does not establish support. Final runtime results and acceptance status belong to the source-bound audit reports. This record describes the adaptations and does not establish complete-page or process WCAG conformance.
